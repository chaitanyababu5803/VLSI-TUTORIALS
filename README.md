Core topics of VLSI (Very Large Scale Integration) focus on designing, verifying, and manufacturing complex integrated circuits using CMOS technology, covering both digital (RTL, synthesis, STA) and analog design, along with physical layout, low-power techniques, and hardware verification using HDLs (Verilog/SystemVerilog). 

Core Subjects and Topics
VLSI Fundamentals: CMOS technology, nMOS/pMOS transistor theory, inverter characteristics, noise margins, and layout design rules (stick diagrams).
Digital Electronics & System Design: Logic gates, flip-flops, FSMs, combinational/sequential circuit design, and computer architecture (pipelining, memory hierarchy).
Hardware Description Languages (HDL): Verilog or VHDL, RTL design, behavioral modeling, and synthesizable code.
Physical Design (Back-End): Floorplanning, placement, routing, clock tree synthesis (CTS), and parasitic extraction.
Verification and Testing: Functional verification, simulation, Static Timing Analysis (STA - setup/hold checks), and Design for Testability (DFT).
Advanced Topics: Low-power VLSI design (leakage reduction), mixed-signal IC design, ASIC design, and FPGA prototyping. 

Key EDA Tools (Industry Standard)
Simulation/Verification: ModelSim, Synopsys VCS, Cadence Incisive, UVM.
Synthesis/Physical Design: Synopsys Design Compiler, Cadence Virtuoso/Innovus, Mentor Graphics Calibre. 

Required Skill Sets
Languages: Verilog, SystemVerilog, Tcl, Python, Perl.
Fundamental Knowledge: Network theory, analog electronics, semiconductor device physics.
